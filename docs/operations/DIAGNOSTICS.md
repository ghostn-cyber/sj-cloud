# Platform Diagnostics operations

The diagnostics manager runs automated audits verifying system and container states.

## Diagnostics Paths
- `/admin/diagnostics`: Full audit report
- `/admin/runtime`: OS, CPU, RAM utilization
- `/admin/network`: Bound ports, interface list
- `/admin/services`: Service mesh and ingress configuration
- `/admin/applications`: Registered tenant app lists
- `/admin/pipelines`: Worker queues and sync statuses
